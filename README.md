Tasks for the course "Probabilistic Artificial Intelligence" by Prof. Andreas Krause at ETH Zürich.

Task 1 : Gaussian Process to predict pollution concentration across a city based on geographical coordinates.

Task 2: Bayesian Deep Learning using Stochastic Weight Averaging - Gaussian (SWAG) to solve an image classification problem (predicting weather conditions like "snow" and "clouds").

Task 3: Bayesian Optimization to maximize a property of a protein (logP) satisfying constraints(SA).

Task 4: Reinforcement Learning (TD3) to solve the cartpole problem.
